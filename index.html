Apa itu HTML?

HTML singkatan dari HyperText Markup Language. Ini adalah fondasi dari setiap halaman web yang kita lihat sehari-hari. HTML digunakan untuk menentukan struktur konten, seperti paragraf, judul, gambar, dan tautan.

Saat belajar HTML, kita akan sering berurusan dengan tag atau elemen. Misalnya, submission ini wajib menggunakan elemen semantik seperti header, nav, main, article, aside, dan footer.
